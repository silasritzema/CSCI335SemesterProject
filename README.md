# B.E.N (Beat Editing Navigator)

## Overview
B.E.N is an accessible DAW prototype that uses webcam-detected hand gestures to trigger musical chords. The project is designed to explore how blind and visually impaired users can interact with music software through gesture-based input instead of primarily visual controls.


## Features
- Accessible DAW interface built for blind and visually impaired users
- Webcam-based hand tracking for touch-free musical interaction
- Real-time gesture to chord mapping
- Audio engine powered by Tone.js for clear chord playback
- React-based front end for a smooth user experience

## Tech Stack
- **React** for building the UI
- **Tone.js** for real-time audio playback
- **MediaPipe** for hand tracking and gesture recognition
- **JavaScript** for logic
- **Vite** for development and build setup

## Installation

### Prerequisites
- Node.js
- npm

### Setup

1. Clone the repository:
```bash
git clone git@github.com:silasritzema/CSCI335SemesterProject.git
cd CSCI335SemesterProject/client
```
2. Install dependencies
```bash
npm install
```
3. Start development server
```bash
npm run dev
```
4. Open the localhost URL shown in the terminal and allow webcam access
